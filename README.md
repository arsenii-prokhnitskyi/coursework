# UnApp — аналітика та планування проєктів

Навчальний сайт сервісу планування завдань, контролю строків, бюджету та
завантаження команди. HTML5, CSS3, Flexbox/Grid, Vanilla JavaScript.
Три взаємопов’язані сторінки за макетом UnApp з українським контентом.

## Сторінки

- `index.html` — можливості, тематичні SVG-ілюстрації, матеріали та тарифи.
- `blog.html` — дев’ять коротких матеріалів про планування й аналітику.
- `services.html` — опис сервісу та ролі демонстраційної команди.
- `404.html` — повідомлення про відсутню сторінку.

## Запуск

Відкрийте проєкт через Live Server у VS Code. Або, якщо є Python:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Адреса: `http://127.0.0.1:8080/`. HTTP потрібен для зовнішнього SVG-спрайта.

## Функціональність

Мобільне меню, кнопка нагору, модальна форма з валідацією імені/email/довжини
після обрізання пробілів, закриття кнопкою/Escape/фоном, цикл і повернення
фокуса, інформація про приватність, обробка відсутніх зображень.
CSS Sprite використано для іконок можливостей, SVG Sprite — для інших іконок.

Форми перевіряють введення локально: дані не надсилаються та не зберігаються.
Немає оплати чи справжньої розсилки. Умовність тарифів, показників і команди
позначена. Пагінація 2–4 неактивна; додаткових статей або відео не створювали.

## Структура

- `assets/css/style.css` — спільні стилі й адаптивні компоненти.
- `assets/js/main.js` — поведінка на Vanilla JavaScript.
- `assets/images/` — оптимізовані WebP, SVG-схеми, спрайти, favicon і заглушка.
- `docs/figma-reference/`, `figma-test/` — оригінали та довідкові матеріали;
  не входять до переліку файлів сайту для публікації.
- `docs/quality/` — відповіді W3C, результати тестів, скриншоти й manifest.

Композиція за наданим Figma-макетом і [Colorlib Unapp](https://colorlib.com/wp/template/unapp/).
Фотографії надані разом із макетом. Тематичні SVG-схеми містять умовні
навчальні дані та не видаються за скриншоти працюючого сервісу.

## Готовність до публікації

Актуальний [передпублікаційний звіт](docs/prepublication-report.md) містить
покриття вимог і результати перевірок. Старі `development-*.md` — історія
попередніх етапів, а не опис поточної версії.

Код сайту читабельний; клієнтських фреймворків і Node.js-залежностей немає.
Render та API відкладені, база даних не потрібна за уточненням користувача.
PageSpeed і маршрутизація 404 на хостингу перевіряються після публікації.
